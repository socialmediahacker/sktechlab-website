# Neon Blueprint Homepage Redesign

## Goal
Rebuild only the public homepage as a near-black, high-tech “AI Website Blueprint” workbench. Preserve all existing routes, backend queries, templates, authentication, builder, dashboard, and admin behavior.

## Homepage structure
1. **Blueprint header**
   - Left: blueprint-style SKETCH LAB mark and cyan subtitle.
   - Center: four live system-status indicators.
   - Right: `View Templates` and `Start Building` actions.
   - Mobile: compact brand, condensed status, and accessible menu/actions.

2. **Two-column builder hero**
   - Left: all-caps condensed headline, copy, neon outline markers, prompt textarea, editable example chips, voice/action controls, trust metrics, and feature badges.
   - Right: oversized live preview panel with status labels, desktop/tablet/mobile controls, and generated floral-studio website artwork.
   - Prompt submission continues into the existing `/start` builder flow.

3. **Template browser**
   - Segmented tabs for `Website`, `E-Commerce`, `Personal`, and `Blog`.
   - Dense four-column grid using existing featured/live template data, preview links, category tags, animated status accents, and clear empty fallbacks.
   - `Browse All Templates` links to the existing category system.

4. **Proof and content sections**
   - Four stat blocks, cyan quote card, reviews, help CTA, and a three-card blog strip.
   - Reuse existing public reviews and blog data; keep all links functional.
   - Compact technical footer with legal copy, resource links, status, and social buttons.

## Visual system
- Scope a dedicated homepage theme so shared pages retain their current look.
- Near-black canvas, faint blue grid, cyan/electric-blue accents, white type, muted blue-gray labels, minimal amber/red status signals.
- Monospaced technical typography, condensed display headings, square or subtly clipped controls, blueprint borders, brackets, crosshair details, scanning lines, and restrained motion.
- Generate one original floral-studio preview asset for the hero; existing template thumbnails remain data-driven.

## Responsive behavior
- Stack hero and preview vertically on tablets/mobile.
- Convert dense navigation/status rows into compact controls without horizontal overflow.
- Keep template cards readable at one/two columns and preserve large touch targets.
- Respect reduced-motion settings and avoid layout-shifting animations.

## Verification
- Validate prompt/chip/voice/device/tab interactions and all primary links.
- Check desktop and 390px mobile screenshots for fit, hierarchy, and no overlap.
- Verify `/`, `/start`, template previews, categories, blog links, and sign-in remain functional.
- Confirm current build/runtime logs stay clean; do not modify non-homepage business logic.
